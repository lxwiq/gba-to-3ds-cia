5Import an emulator save

Continue a game started in an emulator. The save is converted here, then injected on the console with GodMode9. This is separate from the build.

Auto picks the type from the file size. It must match the game.

Inject the save with GodMode9

  1. Install the .cia, start the game once, save in game, then quit with HOME.
  2. Copy the converted .sav to the SD card.
  3. Hold START while powering on to open GodMode9 (do not let the HOME Menu start first).
  4. In GodMode9 select the .sav file and press Y to copy it.
  5. Open [S:] SYSNAND VIRTUAL, select agbsave.bin, choose "AGBSAVE options..." then "Inject GBA VC save" and confirm.
  6. Restart normally and start the game: your save is loaded.

Checkpoint 4.0 or newer can also restore GBA VC saves after the game has saved once.

FBI shows error C8A04555 when browsing the save data of any GBA Virtual Console title. This is normal.
